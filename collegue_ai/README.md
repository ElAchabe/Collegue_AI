# Collegue AI — Prototype

Collegue AI is an offline-first planning assistant for ICT teachers in Moroccan middle schools.

## First prototype scope

- Clean official curriculum, calendar, and pedagogical memory data.
- Generate annual planning for 1AC, 2AC, and 3AC.
- Display official units and sub-modules.
- Display the official academic calendar.
- Display the pedagogical planning framework.

## Tech stack

- Python
- FastAPI
- Streamlit
- JSON files
- Local offline storage

## Run

### Linux

bash run_linux.sh

### Windows

run_windows.bat
